## API Reference

### `<twig:ui:Skeleton>`

| Prop | Type | Description |
|---|---|---|
| `animation` | `'shimmer'` \| `'pulse'` \| `'none'` | The loading animation. Defaults to `shimmer` |
| `as` | `string` | The HTML tag to render. Defaults to `div` |
