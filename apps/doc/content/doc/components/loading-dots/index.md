## API Reference

### `<twig:ui:LoadingDots>`

| Prop | Type | Description |
|---|---|---|
| `size` | `'sm'` \| `'md'` \| `'lg'` \| `'xl'` | The size of the dots. Defaults to `md` |
| `label` | `string` | The accessible label announced to assistive technologies. Defaults to `'Loading'` |
